# 测试素材说明

本项目当前使用的声音与材质测试素材均由本仓库脚本确定性生成，可安全用于代码仓库、录屏、求职作品集与技术演示。

## 声音素材

位置：`Demo/TestAudio/Generated`

- 软、中、硬三档金属撞击 WAV。
- 由 `scripts/generate_test_impacts.ps1` 合成。
- 用于 Wwise Random Container、Event 与 SoundBank 的真实播放链路测试。

## 材质贴图

位置：`Demo/TestMaterials/Generated`

- 拉丝钢：冷灰底色、单向拉丝、高光划痕及低粗糙度图。
- 硬木：暖棕底色、波浪木纹、木结及中高粗糙度图。
- 薄玻璃：青蓝磨砂颗粒、放射状裂纹及低粗糙度图。
- 每张贴图为 1024×1024 PNG，由 `scripts/generate_material_textures.ps1` 生成。

Unreal 端的 `generate_visual_assets.py` 会自动导入贴图、配置 sRGB/Mask 压缩、创建材质与材质实例。玻璃材质使用半透明双面表面；钢、木材质分别使用对应金属度与粗糙度设置。

后续若替换为社区公开素材，应在本文件补充来源链接、许可证、作者、修改内容和分发限制；没有明确许可证的素材不进入仓库。

## 本机 Fab 增强布景（不随仓库分发）

- 素材名：Carpenter's Workshop Environment
- 类型：Fab / Unreal Asset Pack，无代码模块。
- 素材内部版本：UE 5.2；清单声明兼容 UE 4.27～5.8。
- 本机验证：UE 5.8.1 可加载示例关卡、木工台、锤、木槌、木板、金属板与工具箱。
- 用途：为声学工坊提供更可信的工作台语境；不承担插件逻辑，也不是公开仓库的运行依赖。
- 分发：`Demo/Content/CarpentersWorkshop/` 已被 Git 忽略，仓库只提供增强地图生成脚本。使用者需从自己的 Fab 库安装该素材。

增强地图路径为 `/Game/CarpentersWorkshop/ResonanceForge/L_RF_WorkshopShowcase`，同样位于忽略目录中。这样既能在本机展示高质量布景，又不会把受 Fab 条款约束的源资产重新分发。
