# 测试素材说明

本项目当前使用的声音与材质测试素材均由本仓库脚本确定性生成，可安全用于代码仓库、录屏、求职作品集与技术演示。

## 声音素材

位置：`Demo/TestAudio/Generated`

- 拉丝钢、硬木、薄玻璃三种材质，每种包含软、中、硬三档，共九份 WAV。
- 由 `scripts/generate_test_impacts.ps1` 合成。
- 频率组与 UE 内置材质模态保持同一设计方向，同时加入各材质不同的衰减与噪声比例；不是把一份金属采样改名复用。
- 分别进入三个 Wwise Random Container、三个 Event 与同一 SoundBank，用于真实材质分流播放。

## 材质贴图

位置：`Demo/TestMaterials/Generated`

- 拉丝钢：冷灰底色、单向拉丝、高光划痕及低粗糙度图。
- 硬木：暖棕底色、波浪木纹、木结及中高粗糙度图。
- 薄玻璃：青蓝磨砂颗粒、放射状裂纹及低粗糙度图。
- 每张贴图为 1024×1024 PNG，由 `scripts/generate_material_textures.ps1` 生成。

Unreal 端的 `generate_visual_assets.py` 会自动导入贴图、配置 sRGB/Mask 压缩、创建材质与材质实例。玻璃材质使用半透明双面表面；钢、木材质分别使用对应金属度与粗糙度设置。

后续若替换为社区公开素材，应在本文件补充来源链接、许可证、作者、修改内容和分发限制；没有明确许可证的素材不进入仓库。

## 共享声学配方

位置：`Demo/Content/ResonanceForge/Profiles`

- `DA_RF_LongTailWoodString`：长尾木弦，使用硬木六模态、指腹起振、`0.9987` 反馈、`0.22` 阻尼、`0.44` 箱体耦合和 `0.82` 弦心侧拾音位置。
- 由 `Demo/Scripts/generate_physics_lab.py` 确定性创建并挂到数字波导弦 Actor。
- 是本项目自行定义的数据资产，不包含第三方采样或受限内容，可随仓库和作品集分发。
- 场景复检会重新加载磁盘地图，并确认数字弦引用该资产及对应参数。

## 本地铸样输出

位置：`Demo/Saved/ResonanceForge/Exports`

- 由插件“铸样台”调用实时 Synth 的同一套模态或数字波导 DSP 离线生成，不依赖第三方采样。
- 输出格式固定为 `48 kHz / 16-bit / stereo WAV`，时长可选 1.5、3 或 6 秒；重名自动追加编号，避免覆盖试听版本。
- 当前模型、共振齿列、弦上起振位置、激励手势、弦床（含拾音位置）、Note、原始力度与力度响应曲线都会进入渲染；弓擦的持续摩擦与实时 Synth 共用同一 Voice 渲染函数。
- 插件从每次真实铸样提取 180 段归一化峰值包络，并测量末 100 ms RMS 相对全段峰值；高于 `−48 dB` 时提示潜在尾音截断。
- 每份 WAV 同步生成 `.rfrecipe.json` 声源铭牌，模式标识为 `resonance-forge/sample-label/v1`；记录生成器版本、音频规格、全部模态、波导参数、演奏参数及 Wwise 路由语义。
- WAV 与铭牌按同一基础名配对。只有两者都写入成功才报告完成；WAV 写入失败时会撤回先生成的铭牌。
- 当前铭牌保存 180 段 `envelopePeaks`、`source.strikePosition`、`performance.velocityCurve`、`waveguide.pickupPosition` 与 `waveguide.excitation`；“回炉最近铭牌”会检查配套 WAV 的实际 RIFF 头、模式版本和字段范围后恢复 UE 当前声源，不信任 JSON 中的 Wwise Event 去覆盖材质路由。旧 v1 缺少演奏映射时按线性响应，缺少波导新字段时继续使用中性拾音位置与拨片手势兼容恢复。
- “铭牌架”按 `generatedAtUtc` 索引最近三份本地结果，只保存路径与摘要，不复制 WAV 或受限素材；点击某格后仍使用完整回炉校验。
- 该目录属于本机派生结果并被 Git 忽略。需要作为正式测试素材发布时，应人工筛选、重命名并补充用途说明后再移动到受版本控制的目录。
- 这是 UE 原始物理声源，不包含 Wwise Bus、Effect、空间化或母带处理，也不会自动导入 Wwise 工程。

## 本机 Fab 增强布景（不随仓库分发）

- 素材名：Carpenter's Workshop Environment
- 类型：Fab / Unreal Asset Pack，无代码模块。
- 素材内部版本：UE 5.2；清单声明兼容 UE 4.27～5.8。
- 本机验证：UE 5.8.1 可加载示例关卡、木工台、锤、木槌、木板、金属板与工具箱。
- 用途：为声学工坊提供更可信的工作台语境；不承担插件逻辑，也不是公开仓库的运行依赖。
- 分发：`Demo/Content/CarpentersWorkshop/` 已被 Git 忽略，仓库只提供增强地图生成脚本。使用者需从自己的 Fab 库安装该素材。

增强地图路径为 `/Game/CarpentersWorkshop/ResonanceForge/L_RF_WorkshopShowcase`，同样位于忽略目录中。这样既能在本机展示高质量布景，又不会把受 Fab 条款约束的源资产重新分发。
