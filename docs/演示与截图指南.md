# 共振铸造台演示与截图指南

## 一分钟演示流程

1. 打开 `ResonanceForgeDemo.uproject`，点击插件中的“打开试听场景”。有 Fab 素材时会进入增强声学工坊，否则进入基础场景。
2. 通过“窗口 → 音频工具”打开“共振铸造台 · 材质声源工作台”，停靠在右侧。
3. 在场景中选择拉丝钢、硬木或薄玻璃共振体，点击“读取当前选择”，展示顶部对象状态与四段声音链同步变化。
4. 在插件中切换材质预设，说明视觉材质与模态共振预设是同一次操作。
5. 调节撞击能量、音色明亮度、共振体尺寸，点击“敲击当前对象”，展示 UE 合成与 Wwise Event 同步触发。
6. 选择右侧数字波导弦，读取选择后切换到“数字波导弦”，按钮随上下文变为“拨动当前弦”。
7. 点击 PIE：三颗球从不同高度落下，撞击时分别出现蓝、橙、青反馈光。
8. 若同时打开 Wwise Profiler，展示三个 RTPC 随撞击参数更新。

## 建议截图

### 01 主视觉

- 完整声学工坊：左侧材质碰撞台、右侧波导弦架、后墙 Wwise 输出区。
- 用于 README 首图与作品集封面。

### 02 插件全貌

- 插件独立放大，完整显示标题、四段信号链、三种材质预设、三个 RTPC 滑杆和状态条。
- 用于说明这是可操作的 UE 编辑器插件，而不是单纯 Demo 场景。

### 03 场景 + 插件联动

- 视口中选择“硬木”共振体，插件显示当前对象、硬木预设及完整声音链。
- 用于证明编辑器选择、视觉材质和声音配置已经联动。

### 04 PIE 撞击瞬间

- 落球接触共振体、材质专属反馈光亮起。
- 用于解释物理输入如何进入音频链路。

### 05 Wwise 参数证据

- Wwise Profiler 中同时显示 `RF_ImpactEnergy`、`RF_ImpactBrightness`、`RF_ObjectSize`。
- 用于证明中间件集成是真实运行链路。

### 06 材质细节

- 拉丝钢横向划痕、硬木年轮木结、磨砂玻璃裂纹的三联近景。
- 用于强调“材质声音控制”不是抽象文字，而是视觉与听觉共同设计。

实际提交作品集时保留 3～4 张即可：主视觉、插件全貌、场景联动、Wwise 参数证据。无需为这个工具单独录制视频。

## 截图验收

- 中文标签完整，无截断或乱码。
- 插件宽度建议不低于 720 px，避免四段信号链拥挤。
- 三种材质必须同时可辨，不能只靠标签区分。
- 至少一张图同时出现演示场景和插件界面。
- 至少一张图包含 Wwise Event / RTPC 的真实名称。
