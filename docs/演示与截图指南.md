# 共振铸造台演示与截图指南

## 一分钟演示流程

1. 打开 `ResonanceForgeDemo.uproject`，点击插件中的“打开试听场景”。有 Fab 素材时会进入增强声学工坊，否则进入基础场景。
2. 通过“窗口 → 音频工具”打开“共振铸造台 · 材质声源工作台”，停靠在右侧。
3. 在场景中选择拉丝钢、硬木或薄玻璃共振体，点击“读取当前选择”，展示顶部对象状态与声源配方同步变化。
4. 在插件中切换材质预设，说明视觉材质与模态共振预设是同一次操作。
5. 调节撞击能量、音色明亮度、共振体尺寸，观察“声纹炉膛”的轮廓随参数变化。
6. 点击“钉住当前声纹”，再切换硬木或薄玻璃；橙色参考轮廓保留，底部显示能量、明亮度与尺度差值。
7. 点击“交换并试听 A/B”，在当前版本和橙色参考之间往返切换；每次交换都会立即试听切换后的版本。
8. 把其中一版存入“甲槽”，切换模型或材质后再召回，展示模型、材质和三项参数同步恢复。
9. 选择右侧数字波导弦，读取选择后切换到“数字波导弦”；“弦床”出现，声纹形态和主按钮随上下文变化。
10. 分别调整回响长度、弦路阻尼和箱体耦合，展示声纹轮廓实时变化；把其中一版钉为参考后进行 A/B 试听。
11. 有 MIDI 键盘时，在“演奏入口”刷新并连接设备；演奏一个音符并推动调制轮，展示 Note、Velocity 与 CC1 实时状态。
12. 选择数字波导弦，展示面板读取“长尾木弦”；Content 浏览器定位随仓库生成的 `DA_RF_LongTailWoodString`。也可以另存一个中文命名变体演示铸印流程。
13. 点击 PIE：三颗球从不同高度落下，撞击时分别出现蓝、橙、青反馈光。
14. 若同时打开 Wwise Profiler，展示三个 RTPC 随撞击参数更新。

## 建议截图

### 01 主视觉

- 完整声学工坊：左侧材质碰撞台、右侧波导弦架、后墙 Wwise 输出区。
- 用于 README 首图与作品集封面。

### 02 插件全貌

- 插件独立放大，完整显示声源配方、声纹炉膛、模型选择、材质预设、三个 RTPC 滑杆和状态条。
- 用于说明这是可操作的 UE 编辑器插件，而不是单纯 Demo 场景。

### 03 场景 + 插件联动

- 视口中选择“硬木”共振体，插件显示当前对象、硬木预设及完整声音链。
- 用于证明编辑器选择、视觉材质和声音配置已经联动。

### 04 A/B 声纹比较

- 以拉丝钢为橙色参考，当前版本切换为硬木或薄玻璃，确保两条声纹轮廓同时可见。
- 用于证明可视化来自实际模型和参数，并展示工具的调音决策价值。

### 05 PIE 撞击瞬间

- 落球接触共振体、材质专属反馈光亮起。
- 用于解释物理输入如何进入音频链路。

### 06 Wwise 参数证据

- Wwise Profiler 中同时显示 `RF_ImpactEnergy`、`RF_ImpactBrightness`、`RF_ObjectSize`。
- 用于证明中间件集成是真实运行链路。

### 07 材质细节

- 拉丝钢横向划痕、硬木年轮木结、磨砂玻璃裂纹的三联近景。
- 用于强调“材质声音控制”不是抽象文字，而是视觉与听觉共同设计。

### 08 MIDI 演奏状态（有硬件时可选）

- 面板显示真实设备名、最近一次 Note、Velocity 和 CC1。
- MIDI 不是必拍证据；没有硬件时不要用虚构数据代替。

### 09 数字弦塑形

- 选择数字波导弦，让“弦床”的三项参数与声纹炉膛同时出现在画面中。
- 推荐用低阻尼、高耦合版本对比高阻尼、低耦合版本，轮廓差异更容易读懂。

### 10 共享配方资产

- 面板显示“长尾木弦”，Content 浏览器显示实际挂载的 `DA_RF_LongTailWoodString`。
- 用于说明作品不只是一次性 Demo：调音结果可以变成项目资产并参与团队版本控制。

实际提交作品集时保留 3～4 张即可：主视觉、插件全貌或 A/B 声纹、场景联动、Wwise 参数证据。无需为这个工具单独录制视频。

## 截图验收

- 中文标签完整，无截断或乱码。
- 插件宽度建议不低于 820 px，让声源配方、声纹炉膛和模型选择保持清晰层级。
- 三种材质必须同时可辨，不能只靠标签区分。
- 至少一张图同时出现演示场景和插件界面。
- 至少一张图包含 Wwise Event / RTPC 的真实名称。
