# 共振铸造台演示与截图指南

## 一分钟演示流程

1. 打开 `ResonanceForgeDemo.uproject`，点击插件中的“打开试听场景”。有 Fab 素材时会进入增强声学工坊，否则进入基础场景。
2. 通过“窗口 → 音频工具”打开“共振铸造台 · 材质声源工作台”，停靠在右侧。
3. 在场景中选择拉丝钢、硬木或薄玻璃共振体，点击“读取当前选择”，展示顶部对象状态与声源配方同步变化。
4. 在插件中切换材质预设；点击后会同步视觉材质与模态共振预设，并立即试听当前结果。
5. 先拖动“落点划线规”，比较近端、中央与远端的模态短齿响应；再在“共振齿列”点击一根齿，调节齿位、齿重与余响，松手后直接试听。
6. 依次点击“轻触 / 常规 / 重击”，先用锤击标尺建立可听的力度参照；指出下方出口刻度同步显示近似的 dB、Low-pass 与 cent。
7. 在“监听闸门”依次切换原声炉、Wwise 出口、双路叠听；每次切换都会用同一组参数试听，顶部“声音出口”随真实路由更新。
8. 再细调撞击能量、音色明亮度、共振体尺寸：拖动时观察“声纹炉膛”和 Wwise 出口刻度同时变化，松手后只触发一次声音。
9. 点击“钉住当前声纹”，再切换硬木或薄玻璃；紫色参考轮廓保留，底部显示能量、明亮度与尺度差值。
10. 点击“交换并试听 A/B”，在当前版本和紫色参考之间往返切换；每次交换都会立即试听切换后的版本。
11. 把其中一版存入“甲槽”，切换模型或材质后再召回，展示模型、材质和整套声源参数同步恢复。
12. 选择右侧数字波导弦，读取选择后切换到“数字波导弦”；“弦床”出现，声纹形态和主按钮随上下文变化。
13. 分别调整回响长度、弦路阻尼和箱体耦合，指出弦路尺的驻波包络与琴桥基座会同步变化；固定这三项，只把青色拾音梭从琴桥拖到弦心，再把其中一版钉为参考进行 A/B 试听。
14. 没有 MIDI 硬件时，直接点击“试音键床”的 G 锤键，并从上到下比较轻重力度；横向拖过数根锤键展示连续演奏。
15. 有 MIDI 键盘时，在“演奏入口”刷新并连接设备；演奏一个音符并推动调制轮，展示 Note、Velocity 与 CC1 实时状态。
16. 在“铸样台”保持 Note、力度、回响、阻尼和耦合不变，先以 `82%` 拾音位置铸一份 `RF_StringCenter_G3`，再以 `8%` 铸一份 `RF_StringBridge_G3`；指出两份 WAV 的差异来自真实延迟线拾音，而不是换预设。点击弦心铭牌，展示硬木、数字波导、完整弦床、Note 和拓片一起恢复并试听。
17. 选择数字波导弦，展示面板读取“长尾木弦”；Content 浏览器定位随仓库生成的 `DA_RF_LongTailWoodString`。也可以另存一个中文命名变体演示铸印流程。
18. 点击 PIE：三颗球从不同高度落下，撞击时分别出现蓝、橙、青反馈光。
19. 保持工作台可见，指出最近一次撞击会把落点、能量和明亮度回传；划线规出现青色落点余辉，模态短齿随能量衰减。
20. 若同时打开 Wwise Profiler，展示当前材质 Event 与三个 RTPC 随撞击参数更新。

## 建议截图

### 01 主视觉

- 完整声学工坊：左侧材质碰撞台、右侧波导弦架、后墙 Wwise 输出区。
- 用于 README 首图与作品集封面。

### 02 插件全貌

- 插件独立放大，主图显示声音配方与声纹炉膛，细节图显示材质预设、锤击标尺、Wwise 出口刻度和配方架。
- 用于说明这是可操作的 UE 编辑器插件，而不是单纯 Demo 场景。

### 03 场景 + 插件联动

- 视口中选择“硬木”共振体，插件显示当前对象、硬木预设及完整声音链。
- 用于证明编辑器选择、视觉材质和声音配置已经联动。

### 04 A/B 声纹比较

- 以拉丝钢为紫色参考，当前版本切换为硬木或薄玻璃，确保两条声纹轮廓同时可见。
- 用于证明可视化来自实际模型和参数，并展示工具的调音决策价值。

### 04B 共振齿列

- 选择硬木，把落点放在近端约三分之一处；划线规下方保留六根不同高度的模态响应短齿。
- 夹住中间一根共振齿并提高齿重与余响，让选中齿呈橙色，同时保留齿位、齿重、余响三个读数。
- 自动导出的青色余辉来自一次真实面板试敲；作品集若要标注为 PIE 证据，应由用户进入 PIE 后在碰撞瞬间自行截图。

### 05 PIE 撞击瞬间

- 落球接触共振体、材质专属反馈光亮起。
- 用于解释物理输入如何进入音频链路。

### 06 Wwise 参数证据

- 工作台先显示当前材质到 `Play_RF_Impact_Steel / Wood / Glass` 的实际出口；Wwise Profiler 中同时显示对应 Event 与 `RF_ImpactEnergy`、`RF_ImpactBrightness`、`RF_ObjectSize`。
- 用于证明材质分流和参数塑形都是实际运行链路。
- 先把监听闸门切到“Wwise 出口”，避免 UE 原声混入听感判断；Profiler 截图仍是 Event / RTPC 实际运行的最终证据。

### 06B 监听闸门

- 保留顶部“声音出口”和下方三档闸门，让选中态落在“Wwise 出口”或“双路叠听”。
- 用同一次锤击依次单听原声炉与 Wwise，再叠听；强调这是统一触发路由，不是三套不同参数预设。
- 监听闸门不会写入声源铭牌，也不会改变离线铸样内容；铸样始终是 UE 原始物理声源。

### 07 材质细节

- 拉丝钢横向划痕、硬木年轮木结、磨砂玻璃裂纹的三联近景。
- 用于强调“材质声音控制”不是抽象文字，而是视觉与听觉共同设计。

### 08 MIDI 演奏状态（有硬件时可选）

- 面板显示真实设备名、最近一次 Note、Velocity 和 CC1。
- MIDI 不是必拍证据；没有硬件时不要用虚构数据代替。

### 08B 试音键床（无需硬件）

- 保留完整十三根锤键、橙色最近音符、力度横线，以及 Note、力度、明亮度读数。
- 自动截图触发一次真实面板试音，可用于证明无硬件成功路径；不要把它标成外接 MIDI 输入。

### 09 数字弦塑形

- 选择数字波导弦，让“弦床”的三项校准参数、弦路尺与声纹炉膛同时出现在画面中。
- 保留琴桥、弦心、对称弦段、驻波包络和青色拾音梭的文字与图形，不要只截参数百分比。
- 推荐固定回响、阻尼和耦合，只拖动拾音梭对比琴桥侧与弦心侧；这样截图和试听都能清楚说明唯一变量。

### 10 共享配方资产

- 面板显示“长尾木弦”，Content 浏览器显示实际挂载的 `DA_RF_LongTailWoodString`。
- 用于说明作品不只是一次性 Demo：调音结果可以变成项目资产并参与团队版本控制。

### 11 锤击标尺与 Wwise 出口刻度

- 让轻触、常规、重击三个手势与三列输出读数同时出现。
- 用于解释 RTPC 不只是工程名词：能量对应响度、明亮度对应低通、尺度对应移调。面板数值是按控制点计算的近似读数，Wwise Profiler 仍是运行时证据。

### 12 铸样台

- 保留完整“余响拓片”、末 100 ms 相对峰值读数、文件名、1.5 / 3 / 6 秒档位、“铸成 WAV”按钮与已生成状态。
- 用于说明调音结果不仅能在面板里试听，也能变成标准音频文件进入 Wwise、DAW 或团队评审。
- 输出是 UE 物理声源的原始铸样，不包含 Wwise Bus、Effect 或母带处理；不要把本地导出状态描述成 Wwise 自动导入证据。
- `−48 dB` 阈值只是尾音剪裁提示，不是响度合格线；最终仍需听音并按项目规范处理。
- 若展示文件目录，让同名 WAV 与 `.rfrecipe.json` 同时出现；铭牌是配方交接数据，不要描述成已自动导入 Wwise。
- 回炉成功截图应保留底部“铭牌回炉完成”、恢复后的 Note 与模态数量；它证明的是 UE 配方恢复，不是 Wwise Authoring 状态。
- 铭牌架截图应至少显示 `RF_StringBridge_G3` 与 `RF_StringCenter_G3` 两版，并让 `◆ 当前回炉` 标记落在弦心版；三格摘要不能被截到无法分辨材质、模型或 Note。

实际提交作品集时保留 3～4 张即可：主视觉、插件全貌或 A/B 声纹、场景联动、Wwise 参数证据。无需为这个工具单独录制视频。

## 自动导出插件工作台

插件标题栏中的“导出工作台截图”会把当前可见工作台写入：

```text
docs/images/resonance-forge-workbench.png
```

仓库维护者可以用后台命令一次生成主视图和下半区细节图，并在完成后自动退出 Unreal Editor：

```powershell
& 'C:\Program Files\Epic Games\UE_5.8\Engine\Binaries\Win64\UnrealEditor.exe' `
  '.\Demo\ResonanceForgeDemo.uproject' `
  '-ExecCmds=ResonanceForge.CaptureWorkbench' `
  -ResonanceForgeCaptureAndExit -nosplash -windowed -ResX=1600 -ResY=1200
```

该命令会打开基础试听场景、选择数字波导弦、建立一组 A/B 参考并输出：

```text
docs/images/resonance-forge-workbench.png
docs/images/resonance-forge-keybed.png
docs/images/resonance-forge-workbench-details.png
docs/images/resonance-forge-mode-rack.png
```

主图之后会单独截取试音键床，在其余参数一致的前提下，依次铸成弦心侧与琴桥侧两份 3 秒 WAV / 声源铭牌，再按弦心铭牌确切路径回炉；细节图保留余响拓片、三格铭牌架和回炉状态，最后切到硬木模态撞击体并调整一根共振齿。全部来自真实 Slate 控件状态，不需要 Computer Use，也不会伪造 MIDI 设备或 Wwise Profiler 数据。自动铸样只写入本机 `Saved/ResonanceForge/Exports`，不会冒充 Wwise 导入；硬件 MIDI 与 Wwise Profiler 证据仍应在设备实际连接时单独截图。

## 试听交互

- 点击材质或模型：完成切换后立即触发当前声音。
- 拖动主参数或弦床：拖动过程只更新声纹与刻度，松开鼠标后触发一次 UE Synth 与 Wwise Event；拾音位置会被每次新音符快照，不会在音频线程中途改写正在衰减的弦。
- 点击共振齿列选择真实模态；拖动齿位、齿重或余响时写回 Synth，松开后试听一次。
- 拖动落点划线规会实时更新模态节点响应；松开后以该位置试听。PIE 物理碰撞则从 `FHitResult.ImpactPoint` 自动计算位置。
- 每次触发记录快照；工作台优先读取 PIE 世界中最近撞击的共振体，并用约五秒的能量余辉显示落点和模态响应。
- 试音键床横向映射 C3–C4，纵向映射力度；按住鼠标横向拖奏时，每进入一根新锤键触发一次 Note。
- 弦路尺只允许拾音梭在琴桥到弦心的半弦范围内移动；拖动时实时写入波导声源和声纹，松手后只试听一次，避免复音尾响掩盖差异。
- 点击锤击标尺：直接写入该手势的能量与明亮度并触发试听，共振尺度保持当前值。
- 点击监听闸门：把当前对象的统一触发层切换为仅原生 Synth、仅 Wwise Event / RTPC 或双路叠听；后续面板、键床、MIDI、键盘和 PIE 碰撞共同遵守该路由。
- 点击“铸成 WAV”：用当前实时 Synth 的同一套 DSP 离线渲染，同时写入版本化声源铭牌；重名时追加编号而不覆盖旧样本。“打开目录”只在用户明确点击时执行。
- 点击“回炉最近铭牌”：先完整校验最近的 v1 铭牌和配套 WAV 真实文件头，再恢复当前对象、可用的余响拓片并试听；失败时保持原状态并给出具体原因。0.20 早期 v1 没有拓片字段，但声源参数仍可恢复。
- 点击“铭牌架”的任意格：按该格确切路径走同一套校验与恢复链；当前回炉版本以 `◆` 标记。排序使用铭牌 UTC 时间，不依赖可能相同的文件时间。
- 铸样完成后，“余响拓片”按 180 段显示真实峰值包络，并用最后 100 ms RMS 相对全段峰值判断尾音是否已经收束。

这种交互避免在连续拖动时堆叠大量撞击或波导复音，同时保留参数变化的即时视觉反馈。

## 截图验收

- 中文标签完整，无截断或乱码。
- 插件宽度建议不低于 820 px，让声源配方、声纹炉膛和模型选择保持清晰层级。
- 三种材质必须同时可辨，不能只靠标签区分。
- 至少一张图同时出现演示场景和插件界面。
- 至少一张图包含 Wwise Event / RTPC 的真实名称。
- 细节图中的出口刻度须清晰可读，并保留“近似读数”的说明。
- 铸样截图须显示真实生成状态；若展示文件属性，应为 48 kHz、16-bit、双声道 WAV。
